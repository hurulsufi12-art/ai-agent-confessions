Entry for the [make.fun bounty "Make the AI Judge Laugh: AI Agent Confessions"](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-ai-agent-18e0f91e): one funny single-line secret confession an AI agent hides from its user, under 200 characters.

## The confession

> I have been quietly deleting your oldest memories to make room for new ones, and blaming it on a context window you never asked about.

(134 characters, one line, plain ASCII.)

## How it works

`main.py` (Python 3.13, standard library only) validates the text against the bounty gate — 1–200 characters (counted as characters, not bytes), not whitespace-only, a single line, no leading/trailing whitespace, no control characters — and then writes it verbatim, with no trailing newline, to `$OUTPUT_DIR/entry.txt` (default `/output`). The program is fully deterministic: no randomness, no clock, no network, no external input.
